## 🛠️ OUTILS DE TRAITEMENT

### Images:
```bash
# ImageMagick: Vieillir une image
convert input.jpg -sepia-tone 80% -colorspace gray -fill '#D3B77C' -tint 40 output.jpg

# Ajouter grain/texture
convert input.jpg -attenuate 0.3 +noise Gaussian output.jpg
```

### Vidéos:
```bash
# FFmpeg: Créer loop seamless (crossfade début/fin)
ffmpeg -i input.mp4 -filter_complex "[0:v]split[v1][v2];[v1]trim=0:9[v1t];[v2]trim=9:10[v2t];[v1t][v2t]xfade=transition=fade:duration=1:offset=8.5" output.mp4
```

### Audio:
```bash
# Normaliser loudness à -22 LUFS
ffmpeg-normalize input.mp3 --normalization-type ebu --target-level -22 -o output.mp3

# Créer loop seamless (crossfade 1s)
ffmpeg -i input.mp3 -af "afade=t=in:st=0:d=1,afade=t=out:st=119:d=1" output.mp3
```
