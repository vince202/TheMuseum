# Le Musée du Tarot

Musée virtuel interactif dédié à l'histoire et la symbolique du Tarot.

## Structure

- `Tarot_museum/tarot-museum/` - Application React (code source principal)

## Développement

```bash
cd Tarot_museum/tarot-museum
npm install --legacy-peer-deps
npm run dev
```

## Build

```bash
npm run build
```

Build produit : 141 KB gzippé, 1784 modules

## Salles du musée

### Implémentées
- **Homepage** - Accueil avec navigation vers les salles
- **Le Vestibule des Initiés** - Première salle avec contenu Gallica BnF
